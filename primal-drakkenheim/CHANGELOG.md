# Changelog

## 1.1.2
- **A wounded Epic Boss stays wounded.** Placing another token of a linked boss (moving it to another scene, say) no longer resets its hit points and Epic Actions once it has been hurt.
- **Party size from the primary party.** With the setting at 0, Epic Bosses count the characters in dnd5e's primary party, then the players' own characters, and only then every player-owned character in the world (which also counted retired characters).
- **Works with Primal Combat's side initiative.** A boss's combatant is flagged with its fixed initiative of 20, which Primal Combat counts when it works out the enemies' number. In side initiative this module no longer forces the boss back to 20 after Primal Combat gives it the enemies' number.
